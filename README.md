# 🚀 DevTools Hub PRO

A high-performance, 100% browser-native developer utility suite designed for modern web development workflows. Built with zero server storage, ensuring complete privacy, blazing-fast execution, and seamless client-side processing.

🌐 **Live Website:** [https://musharibkhalid.github.io/devtools-hub/](https://musharibkhalid.github.io/devtools-hub/)

---

## ✨ Included Utility Suite (8-in-1 Tools)

1. **JSON Formatter & Validator**: Beautify, minify, and check diagnostics on raw JSON strings instantly.
2. **Base64 Converter**: Securely encode text or decode Base64 tokens.
3. **CSS Box-Shadow Generator**: Visually design card elevations using live sliders and copy production-ready CSS.
4. **AI Regex Assistant**: Generate regular expressions from plain English descriptions.
5. **UUID & Password Generator**: Create cryptographically secure UUID v4 tokens and customizable passwords.
6. **Code Minifier**: Compress HTML, CSS, and JavaScript code to optimize loading performance.
7. **JWT Decoder**: Decode JSON Web Tokens to inspect headers and payload claims safely.
8. **SQL Formatter**: Structure and beautify raw database queries.

---

## 🔒 Core Features

* **100% Client-Side Execution:** Runs entirely in your browser using vanilla JavaScript. No data or keys are transmitted to any server.
* **Modern UI & Dark Mode:** Styled with Tailwind CSS, featuring smooth theme switching and real-time tool filtering.
* **Fully Responsive:** Optimized for seamless desktop and mobile developer experiences.
